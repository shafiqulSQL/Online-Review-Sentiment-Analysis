# Online-Review-Sentiment-Analysis
Sentiment classification (positive/negative/neutral) on 1,200 online reviews using TF-IDF features and three ML models (Logistic Regression, Multinomial Naive Bayes, Linear SVM).

## Contents
- `report/` — full project report
- `notebooks/` — notebook used to generate all results in the report
- `data/` - the dataset contains 1,200 synthetic reviews
  
## How to run
Open `notebooks/Online-Review-Analysis.ipynb` in Jupyter and run all cells.
Requires: pandas, numpy, seaborn, matplotlib, string, re, nltk, scikit-learn.
